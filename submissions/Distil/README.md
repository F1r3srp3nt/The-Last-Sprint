# Distil: packaged submissions

Packaged builds of Distil, one folder per operating system. These folders hold uploaded packages only, never source code.

**A folder existing does not mean a build exists or that the platform is supported.** Each folder's README says whether a build has been uploaded and what was verified.

| Operating system | Folder |
|---|---|
| macOS | [`MacOS/`](MacOS/README.md) |
| Windows | [`Windows/`](Windows/README.md) |
| Linux | [`Linux/`](Linux/README.md) |
| Android | [`Android/`](Android/README.md) |
| iOS | [`iOS/`](iOS/README.md) |

## Source

The source in [`distil/`](../../distil/README.md) builds a macOS 14+ SwiftUI app (`Distil.app`). Its core library and tests also build on Linux, but there is no Linux, Windows, Android or iOS app.
